# Перенос сайта на Timeweb

## 1. Загрузить файлы

В панели Timeweb → «Файловый менеджер» → папка сайта `centrpolya.ru/public_html`.
Загрузить всё содержимое репозитория, кроме папки `.git`:

- `index.html`, `send.php`, `config.example.php`, `.htaccess`, `robots.txt`
- картинки `bg.jpg`, `bg-2.jpg`, иконки, `logo-white.svg`
- папки `img/` и `fonts/`

Файл `.htaccess` начинается с точки. Если файловый менеджер его не показывает, включите показ скрытых файлов.

## 2. Ящик для отправки писем

Панель Timeweb → «Почта» → создать ящик `zayavki@centrpolya.ru`.
С него сайт будет отправлять заявки. Письма с ящика на своём домене реже попадают в спам.

## 3. Настройки

В той же папке скопировать `config.example.php` в `config.php` и открыть `config.php`:

- `mail_to`: куда приходят заявки. Уже стоит `centr_polya@mail.ru`.
- `mail_from`: ящик из шага 2.
- `vk_token` и `vk_peer_ids`: для ВКонтакте, см. шаг 5. Пока поля пустые, работает только почта.

`config.php` хранится только на хостинге, в GitHub его нет: ключ ВК никто не увидит.

## 4. Проверка

Открыть сайт, заполнить форму, отправить. Должно появиться «Спасибо! Заявка принята», а письмо придёт на `centr_polya@mail.ru`. Если письма нет во «Входящих», проверьте «Спам» и пометьте письмо как «Не спам».

Если на сайте вместо «Спасибо» появилось «Не получилось отправить заявку», ошибка записана в логах: панель Timeweb → «Логи» → error.log, строки начинаются с `centr-polya send.php`.

## 5. ВКонтакте (по желанию)

1. Группа → Управление → Сообщения → включить «Сообщения сообщества».
2. Управление → Работа с API → Создать ключ, поставить галочку «Сообщения сообщества». Ключ вставить в `vk_token`.
3. Тот, кому должны приходить заявки, один раз пишет в группу любое сообщение.
4. Его числовой ID (цифры из ссылки `vk.com/id123456`) вписать в `vk_peer_ids`, например `[123456]`. Можно несколько ID через запятую.
